# 装箱项目用户手册

本手册面向系统使用者，说明如何完成装箱计算、如何准备数据，以及填写配置时需要注意的业务口径。

## 一、系统可以做什么

系统主要用于膜卷装车方案计算，当前包含两种装箱方式：

1. 托盘装箱
   - 先将膜卷放到托盘上，形成小托或整托，再把整托装入车箱。
   - 支持混装、横放、膜叠膜、泡沫高度、托盘超出范围等设置。
   - 计算分两步：先确认规格，再生成最终装箱方案。

2. 悬空装箱
   - 根据叠膜规则、木托/木架、挡板等辅材，生成悬空摆放方案。
   - 会输出车箱装载图、辅材需求清单、未装入货物信息。

系统还提供基础资料维护，包括车箱、托盘、纸管、规格表、用户和部门等。

## 二、使用前准备

开始计算前，建议先检查以下基础资料：

- 车箱管理：确认车箱长、宽、高、载重正确。
- 托盘管理：确认托盘尺寸、重量、类型正确。
- 纸管管理：确认纸管规格正确，因为系统会用它计算膜卷直径。
- 规格表管理：托盘装箱时会用到“单托盘可放个数”，如不准确，可在计算过程中手动修改。

货物 Excel 建议包含以下列。必填列用于计算，选填列主要用于结果展示或由系统自动补齐。

| 列名 | 是否必填 | 说明 |
| --- | --- | --- |
| 品名 | 必填 | 货物名称 |
| 订单厚度 | 选填 | 订单上的厚度，主要用于结果展示；不参与核心计算 |
| 厚度 | 必填 | 实际厚度，用于计算直径和重量 |
| 宽度 | 必填 | 膜卷宽度，用于计算高度或托盘/挡板尺寸 |
| 订单长度 | 选填 | 订单上的长度，主要用于结果展示；不参与核心计算 |
| 长度 | 必填 | 实际长度，用于计算直径和重量 |
| 卷数 | 必填 | 此规格的膜卷数量 |
| 密度 | 选填 | 不填时使用页面默认密度 |
| 重量 | 选填 | 不填或与计算差异较大时，系统会重新计算 |
| 直径 | 选填 | 不填时系统根据纸管、厚度、长度自动计算 |
| 优先级 | 选填 | 不填时默认为普通优先级 |

## 三、通用操作流程

1. 登录系统。
2. 进入对应装箱模块：托盘装箱或悬空装箱。
3. 在“规则设置”页填写订单号和装箱规则。
4. 在“车箱配置”页选择车箱类型和数量。
5. 在“数据导入”页上传货物 Excel。
6. 检查导入后的货物明细，如有错误可直接编辑并保存。
7. 点击“开始计算”。
8. 等待系统返回结果，页面会自动跳转到结果页。
9. 查看装箱图、未装入货物、辅材清单或历史任务。

注意：点击“开始计算”后，尽量不要离开当前页面，否则可能无法自动跳转到结果页。

## 四、托盘装箱使用说明

托盘装箱适用于“膜卷先上托盘，再整托装车”的场景。

### 1. 规则设置

常用设置说明如下：

| 页面设置 | 怎么填写 | 影响 |
| --- | --- | --- |
| 总规则 | 选择“装满优先”或“平衡优先” | 装满优先更关注车箱利用率；平衡优先更关注各车箱/区域装载均衡 |
| 订单号 | 输入订单编号 | 用于查询任务、结果图和导出文件 |
| 托盘规则 | 选择自动或人工 | 人工模式下需要指定托盘尺寸 |
| 托盘尺寸 | 选择实际使用的托盘 | 影响每托可放范围、总高度和重量 |
| 允许超出托盘长度范围 | 按现场允许值填写，单位 cm | 允许膜卷在托盘长度方向适当超出 |
| 允许超出托盘宽度范围 | 按现场允许值填写，单位 cm | 允许膜卷在托盘宽度方向适当超出 |
| 泡沫高度设置 | 填写每卷膜需要增加的泡沫高度，单位 cm | 会增加实际装载高度 |
| 纸管尺寸 | 选择对应纸管 | 系统据此计算膜卷直径 |
| 是否混装 | 按业务要求选择 | 允许时，不同规格剩余膜卷可组合装托 |
| 默认密度 | 填写常用密度 | 导入数据没有密度时使用 |
| 是否横放 | 按业务要求选择 | 开启后，系统会尝试把剩余膜卷横放到可用空间 |
| 最大横放层数限制 | 填写允许层数 | 控制横放堆叠层数 |
| 横放是否需要托盘 | 按现场要求选择 | 影响横放结果的高度和辅材 |
| 算法参数 x | 按项目约定填写 | 用于横放/优化相关判断 |
| 是否膜叠膜 | 按现场是否允许选择 | 开启后，同规格小托可以上下叠放 |
| 单个膜叠膜最大高度 | 填写单个小托参与叠膜的高度上限，单位 cm | 用于判断单个小托能否叠膜 |
| 总体膜叠膜最大高度 | 填写叠膜组合的高度上限，单位 cm | 用于判断叠膜后的组合是否超高 |

### 2. 车箱配置

在车箱配置页选择本次可用车箱和数量。系统会按照所选车箱的内部尺寸、载重限制进行计算。

### 3. 数据导入

上传 Excel 后，系统会自动读取第一张表。导入后请重点检查：

- 品名是否正确。
- 厚度、宽度、长度是否使用正确单位。
- 卷数是否正确。
- 密度、重量、直径是否明显异常。

若修改了厚度、长度、宽度、密度等数据，请保存该行，系统会重新计算相关数据。

需要取回以前订单的货物数据时，点击“历史订单导出”：

1. 可按订单号或创建日期查询。
2. 在目标订单后点击“导出数据”，下载 Excel。
3. Excel 第一张“订单数据”工作表与导入模板列名一致，可直接重新上传；第二张“订单信息”工作表记录订单号、计算进度和重量单位等信息。
4. 重量按历史订单原来选择的 kg 或 T 还原，重新导入时请保持页面重量单位一致。

### 4. 规格确认

托盘装箱会先弹出规格确认表。这里主要确认“单托盘可放个数”。

- 如果系统已有规格表，会自动带出数量。
- 如果数量不符合现场经验，可在确认表中手动修改。
- 确认无误后再提交，系统会继续计算最终装箱方案。

## 五、悬空装箱使用说明

悬空装箱适用于使用木托/木架、挡板等辅材进行悬空摆放的场景。

### 1. 规则设置

| 页面设置 | 怎么填写 | 影响 |
| --- | --- | --- |
| 叠膜规则 | 根据现场方案选择 | 决定每个装载单元放几卷、用几个木托/木架 |
| 订单号 | 输入订单编号 | 用于查询结果和导出辅材单 |
| 挡板默认厚度 | 填写挡板厚度，单位 cm | 影响辅材清单中的挡板规格 |
| 托盘 | 选择木托或木架 | 木架按 20 cm 高度计算，木托按 15 cm 高度计算 |
| 膜卷宽度阈值 | 填写阈值，通常单位 mm | 宽度小于等于该值时，系统会按双排/翻倍组合处理 |
| 挡板长度增加值 | 填写增加值，单位 cm | 系统会在膜卷直径基础上增加该值，得到挡板面尺寸 |
| 是否允许垂直侧壁 | 按现场要求选择 | 影响装载单元是否允许贴靠侧壁 |
| 纸管尺寸 | 选择对应纸管 | 用于计算膜卷直径 |
| 辅材到货日期 | 选择日期 | 会写入辅材需求单 |
| 默认密度 | 填写常用密度 | 导入数据没有密度时使用 |

### 2. 车箱配置和数据导入

与托盘装箱一致：选择车箱、上传 Excel、检查明细后点击“开始计算”。

### 3. 结果内容

悬空装箱结果一般包含：

- 每个车箱的装载图。
- 每个装载单元的位置和方向。
- 木托/木架规格与数量。
- 挡板规格与数量。
- 辅材需求单。
- 未装入货物信息。

## 六、重要业务口径

### 1. 泡沫高度

泡沫高度只在托盘装箱中使用。填写后，系统会把泡沫高度加到每卷膜的实际装载高度中。

也就是说，泡沫高度会影响：

- 小托高度。
- 整托高度。
- 车箱是否装得下。
- 最终装载高度。

悬空装箱目前没有泡沫高度设置，也不会自动把泡沫高度计入结果。

### 2. 膜叠膜高度

托盘装箱中，“膜叠膜”容易产生口径误解，建议按以下方式理解：

- 最终实际装载高度：包含泡沫高度，且包含托盘高度。
- 页面填写的“单个膜叠膜最大高度”和“总体膜叠膜最大高度”：膜卷本体高度限制，不包括托盘高度、泡沫高度。
- 如果现场要求按“实际占车箱高度”控制，需要提前统一口径。

简单说：结果高度会受到泡沫影响；但页面上的膜叠膜高度限制只跟不含托盘、不含泡沫的膜卷本体高度相关。

### 3. 横放高度

横放是在整托装箱之后，利用剩余空间继续尝试装入膜卷。

- 横放成功后的结果高度会包含托盘高度。
- 最大横放层数会限制横放膜卷的堆叠层数。
- 若选择“横放需要托盘”，结果会计入托盘高度和托盘重量。

### 4. 悬空装箱的木托/木架高度

悬空装箱中：

- 木架按 20 cm 高度计算。
- 木托按 15 cm 高度计算。

该高度不是从托盘管理中读取的，而是系统当前固定口径。

### 5. 膜卷宽度阈值

悬空装箱中，“膜卷宽度阈值”用于判断是否按双排/翻倍组合处理。

- 当膜卷宽度小于等于阈值时，系统会增加单个装载单元可包含的卷数。
- 同时，装载单元占用的宽度也会相应增加。

## 七、结果查看

### 托盘装箱结果

结果页可查看：

- 每个车箱的装箱图。
- 每托包含哪些膜卷。
- 是否存在混装、横放、膜叠膜。
- 未装入或剩余货物。
- 导出的结果文件。

### 悬空装箱结果

结果页可查看：

- 每个车箱的装载图。
- 每个装载单元的摆放位置和方向。
- 木托/木架、挡板用量。
- 辅材需求单。
- 未装入货物。

## 八、个人信息维护

个人信息维护页面用于查看和更新当前登录用户的个人资料。

### 1. 总览标签

总览标签中可查看用户名、部门、电话号码、邮箱等信息。

可维护内容：

- 修改电话号码。
- 修改邮箱。
- 点击“更新”保存修改。

说明：

- 用户名、部门、角色等账号基础信息通常由管理员维护。
- 电话号码和邮箱需按页面校验规则填写。

### 2. 密码标签

密码标签用于修改当前账号登录密码。

操作步骤：

1. 输入旧密码。
2. 输入新密码。
3. 再次输入确认密码。
4. 点击“确认”提交修改。

说明：

- 新密码和确认密码必须一致。
- 旧密码校验通过后才能修改成功。
- 密码修改成功后需重新登录系统。

## 九、后台数据管理

后台数据管理模块仅对管理员开放，普通用户无法进行新增、编辑、删除等管理操作。管理员账号角色为 `admin`。

### 1. 用户管理

用户管理用于维护系统登录账号，支持：

- 查看用户列表，列表支持分页展示。
- 新增用户：填写用户名、密码、部门、角色、电话、邮箱等信息。
- 编辑用户信息。
- 重置用户密码。
- 删除用户。

说明：

- 用户角色通常包含管理员和普通编辑用户。
- 管理员账号具有后台数据维护权限。
- 删除用户前应确认该用户是否存在历史任务记录。

### 2. 部门管理

部门管理用于维护组织部门信息，支持：

- 新增部门。
- 编辑部门名称。
- 删除部门。

说明：删除部门前应确认是否仍有用户归属该部门。

### 3. 车箱管理

车箱管理用于维护车箱规格数据，字段包括：

- 车箱名称。
- 长度，单位 m。
- 宽度，单位 m。
- 高度，单位 m。
- 载重，单位 t。

支持新增、编辑、删除。车箱规格会影响托盘装箱和悬空装箱的计算结果。

### 4. 规格表管理

规格表管理用于维护装箱计算所需的规格基础数据。页面字段以系统实际展示为准，通常包括托盘或卷膜规格相关信息，例如名称、长度、宽度、高度、重量、承重或单托盘可放个数等。

支持新增、编辑、删除。托盘装箱第一阶段会使用规格表数据带出“单托盘可放个数”，如数据缺失或不准确，可在规格确认环节手动修正。

### 5. 托盘管理

托盘管理用于维护托盘类型和托盘规格信息，支持：

- 新增托盘。
- 编辑托盘名称、尺寸、重量、类型等信息。
- 删除托盘。

说明：托盘数据会参与托盘装箱计算；悬空装箱中的木托/木架高度当前按系统固定口径计算。

### 6. 纸筒管理

纸筒管理用于维护纸筒规格，也称纸管尺寸，支持：

- 新增纸筒规格。
- 编辑纸筒名称和近似值。
- 删除纸筒规格。

纸筒规格会用于膜卷直径计算，进而影响装箱结果。

## 十、常见问题

1. 为什么上传 Excel 后直径变了？
   - 如果 Excel 中没有直径，系统会根据纸管、厚度、长度自动计算。
2. 为什么重量和 Excel 里不完全一致？
   - 系统会根据厚度、宽度、长度、密度、卷数计算重量；如果导入重量与计算重量差异较大，会采用计算值。
3. 悬空装箱中有没有泡沫高度？
   - 当前悬空装箱页面和算法都没有泡沫高度配置。
4. 规格确认表里的数量不对怎么办？
   - 默认使用规格表中的数据，如不符合预期可在确认表中手动修改“单托盘可放个数”，再继续计算。
5. 计算后没有跳转结果页怎么办？
   - 可能是计算仍在进行、网络连接断开，或页面中途离开导致消息未接收。可刷新后到历史任务或最新任务中查看结果。
6. 计算后结果存在剩余货物但是显示有大量未使用空间？
   - 可能计算配置有误，重新检查相关配置，尤其是重量、高度相关属性。
